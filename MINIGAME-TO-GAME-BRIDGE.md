# From demolition minigame to the full game

The minigame is becoming the first playable slice of the larger Wizards Only Fools structure.

## What already carries forward

- Seeded runs become save-compatible contract seeds.
- Bounty streaks become the first visible version of the persistent nemesis system.
- Impact zones become body, vehicle, and prosthetic sockets.
- Scrap, repairs, ammunition, and Wayfarer trade become the economy foundation.
- Proximity banter and radio bursts become authored faction memory and investigation clues.
- `ASCENT`, `DESCENT`, and `LIMBO` become the first three branches of the Tree of Life route system.

## Tree of Life save variations

Each save should retain a route record rather than a single moral score:

- **ASCENT**: protect, repair, bargain, and help the beings pulling from above.
- **DESCENT**: hunt, break contracts open, and work with the forces pulling from below.
- **LIMBO**: preserve the rebirth system, trade certainty for information, and help people who are trapped between states.

The same named target can appear in multiple saves with a different remembered history. The target ID stays stable; the route events, injuries, allies, and discovered pages differ. That lets the character tree become a document the player reconstructs over time instead of a checklist shown all at once.

## Audio direction

The current prototype uses text timing only. A later audio pass can assign each faction a fictional radio voice, interruption style, and filter. The system should use authored or licensed performances and clearly fictional processing; it should never imitate a real person’s voice without permission. Combat proximity, radio interference, and the Tree route can all choose from the same event history so the banter reacts to what the player actually did.

## The first complete slice

1. Choose a seeded contract.
2. Enter Scrap Tide or Dust Circuit.
3. Read a faction clue through banter or radio.
4. Make a combat, mercy, trade, or escape choice.
5. Carry the consequence into the next run or save page.
6. Unlock one Tree of Life page and one changed relationship.

That slice is enough to test the core promise before building a huge world.
