# Play Lab

The project now keeps the technical connection screen as its default startup, with an **OPEN PLAY LAB** button. For a direct launch, run `Start-PlayLab.ps1` from this folder.

## Current slices

- **Scrap Tide**: a small demolition boating arena. Each seeded run assigns a named bounty contract, a target (wrecks or salvage), and a bonus. Ram rival boats, build a streak, collect salvage, boost, and survive the timer.
- **Dust Circuit**: a seeded third-person sandbox with a first-person toggle, hostile Cinders, teal Wayfarer traders, loot caches, landmarks, a repair/ammo trade, and a radar HUD.

## Controls

- `1` / `2`: switch slices from the menu
- `WASD`: move or steer
- `Mouse`: aim the world camera
- `F`: first-person / third-person toggle in Dust Circuit
- `E`: trade at the Wayfarer post
- `Left mouse`: fire in Dust Circuit
- `R`: restart the current run or generate a new world seed
- `Esc`: return to the menu

This is intentionally a systems blockout: the next pass can replace the primitives with final art, add persistent faction reputation, and deepen the bounty/rival contract loop without changing the testable foundations.
