# X-ray plates

Original. Each is a frame of the game's own X-ray loading screen
(systems/xray_specimen.gd + shaders/anatomy_film.gdshader), run through
Photoshop 2025 filters by script on 2026-09-24, with feathered edges:

- xray_plate_painted: Diffuse Glow, Glass (frosted), Add Noise
- xray_plate_ripple: Ocean Ripple, Add Noise (from the datamosh stage)
- xray_plate_twirl: Twirl, Diffuse Glow, Add Noise (from the dither stage)

Drawn behind the live scan by systems/interstitial.gd, one per destination.
